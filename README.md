# gimps-gpu — образ для поиска простых Мерсенна на арендованной GPU

Образ Docker и скрипты, которые разворачивают на любой машине с NVIDIA GPU всё нужное для GIMPS.
Задания получаются и результаты отправляются в PrimeNet автоматически, под вашим логином mersenne.org.

| Компонент | Версия | Что делает |
|---|---|---|
| **PRPLL-NTT** (`prpll-cuda`, `prpll-ocl`) | gwoltman/gpuowl @ `5ce7df1` (v8.0-449, 2026-10-09) | PRP-тесты на простоту (основная работа: проверка кандидатов около 140M) |
| **mfaktc** | 0.24.1 | Trial factoring (TF) на GPU |
| **AutoPrimeNet** | 2.0.2 | Берёт задания из PrimeNet, отправляет результаты, загружает PRP-proof |
| `gimps-start` / `gimps-status` / `gimps-stop` | — | Запуск на всех GPU, статус, корректная остановка |

Архитектуры: V100, T4/RTX 20xx, A100, RTX 30xx/A10, RTX 40xx/L4/L40, H100, B200, RTX 50xx/RTX PRO 6000.
**Требования к хосту:** драйвер NVIDIA ≥ 570 (CUDA 12.8+). На vast.ai это фильтр *CUDA ≥ 12.8*.

---

## 0. Что считать: PRP или TF

**PRP (`GIMPS_MODE=prp`, по умолчанию)** — это и есть поиск нового простого Мерсенна. С появлением PRPLL-NTT (целочисленные и FP32-гибридные преобразования) потребительские RTX считают PRP быстро, и слабый FP64 больше не мешает. Бенчмарки авторов (сборка 2026-10-09, экспонента 136 279 841):

| GPU | мкс/итерация | ≈ часов на один тест ~140M |
|---|---|---|
| RTX PRO 6000 Blackwell | 125 | ~4,9 |
| RTX 5090 | 135 | ~5,3 |
| H100 (сборка августа) | 182 | ~7,1 |
| A100 (сборка августа) | 332 | ~12,9 |
| RTX 4070 Ti Super | 325 | ~12,6 |
| RTX 4060 | 1071 | ~42 |

**Стоимость одного теста** = `мкс/ит × экспонента / 3,6·10⁹ × $/час`.
Пример: 5090 за $0,40/ч → 135 × 140M / 3,6e9 ≈ 5,25 ч → **≈ $2,1 за тест**.
Реальную скорость PRPLL пишет в лог (`us/it`). Сверьте её с ценой за первые 10 минут и сравнивайте варианты по этой формуле.

**TF (`GIMPS_MODE=tf`)** — поиск делителей (mfaktc). Простое так не найти, но для проекта это полезная работа, и быстрее всего она идёт на картах с сильным INT32. Задания короткие (минуты–часы), поэтому TF удобен для коротких или прерываемых (interruptible) аренд.

## 1. Подготовка (один раз): собрать образ через GitHub

Docker на телефоне или ноутбуке не нужен: образ собирает GitHub Actions бесплатно.

1. Создайте на GitHub **новый репозиторий** (например `gimps-gpu`, можно Private).
2. Загрузите туда **всё содержимое архива**, включая скрытую папку `.github/` (Add file → Upload files, или `git push`).
   Ветка должна называться `main`.
3. Откройте вкладку **Actions**. Workflow `build-image` запустится сам и будет работать ~15–25 мин. Дождитесь зелёной галочки.
4. Сделайте образ публичным, чтобы облако скачивало его без логина. Профиль → **Packages** → `gimps-gpu` → Package settings → *Change visibility* → **Public**.
   В образе нет никаких секретов: логин передаётся переменной при запуске.
   Если образ нужен приватным, впишите в шаблон vast.ai логин GitHub и токен с правом `read:packages`.

Ваш образ: **`ghcr.io/<ваш-логин-github-маленькими-буквами>/gimps-gpu:latest`**

> Обновить PRPLL до свежего master: Actions → build-image → *Run workflow* → `prpll_ref = master`.

## 2. Вариант A — vast.ai с готовым образом (рекомендуется)

**Создать шаблон** (Templates → New), один раз:

| Поле | Значение |
|---|---|
| Image | `ghcr.io/<логин>/gimps-gpu:latest` |
| Launch mode | **SSH** (так можно зайти и посмотреть статус) |
| Docker options | `-e GIMPS_USER=<логин mersenne.org> -e GIMPS_MODE=prp` |
| On-start script | см. ниже |
| Disk | **≥ 50 ГБ** на 1 GPU (+30 ГБ на каждую следующую). Под proof-файлы нужно ~18 ГБ на тест |

On-start script:
```bash
export GIMPS_USER=<логин mersenne.org>   # дублируем на случай, если env не прокинулся
export GIMPS_MODE=prp                    # или tf
gimps-start --daemon
```

**Арендовать:** выберите оффер с фильтром *CUDA ≥ 12.8* и этим шаблоном. Примерно через 1–2 минуты после старта:
```bash
ssh -p <порт> root@<ip>      # команда есть в карточке инстанса (кнопка >_)
gimps-status
```

> В SSH-режиме vast.ai не выполняет ENTRYPOINT образа, поэтому запуск идёт через On-start.
> В режиме *Entrypoint* можно оставить поле On-start пустым: образ сам вызовет `gimps-start`.

## 3. Вариант B — без своего образа (bootstrap)

Подходит, если не хочется возиться с GitHub, или нужна разовая проба.

1. Арендуйте инстанс с образом **`nvidia/cuda:12.8.1-devel-ubuntu24.04`** (SSH-режим, диск ≥ 50 ГБ).
2. Скопируйте `bootstrap.sh` на машину. Либо `scp -P <порт> bootstrap.sh root@<ip>:`, либо откройте файл, скопируйте текст и вставьте в `nano bootstrap.sh`.
3. На машине:
```bash
bash bootstrap.sh                                # сборка 3–6 минут
GIMPS_USER=<логин> GIMPS_MODE=prp gimps-start --daemon
gimps-status
```
После пересоздания инстанса сборку придётся повторить. При остановке и запуске того же инстанса всё сохраняется.

## 4. Вариант C — обычная облачная VM (любой провайдер)

На VM нужны драйвер NVIDIA ≥ 570, Docker и NVIDIA Container Toolkit. В GPU-образах облаков (Deep Learning VM и т.п.) они обычно уже стоят.
```bash
docker run -d --name gimps --gpus all --restart unless-stopped \
  -v gimps-data:/data \
  -e GIMPS_USER=<логин> -e GIMPS_MODE=prp \
  ghcr.io/<логин-github>/gimps-gpu:latest

docker exec gimps gimps-status       # статус
docker logs -f gimps                 # общий лог
docker stop -t 120 gimps             # корректная остановка (чекпойнт)
```

## 5. Как понять, что всё работает

- `gimps-status` показывает загрузку GPU (должна быть ~100%), задание в `worktodo` (строка `PRP=...`) и последние строки лога PRPLL с `us/it` и ETA.
- Через ~1 час машина появится на https://www.mersenne.org/cpus/ под именем `cloud-prp0` (`cloud-prp1`… для других GPU).
- Логи лежат в `/data/logs/`: `prp-gpu0.log` (PRPLL), `apn-gpu0.log` (AutoPrimeNet), `gimps-start.log`.
- Все рабочие файлы и чекпойнты хранятся в `/data/prp-gpu<N>/`.

## 6. Завершение аренды — важно

Каждое задание закреплено за вами. Брошенное задание висит, пока не истечёт срок, и тормозит проект. Порядок такой:

| Ситуация | Команда |
|---|---|
| Хочу закончить аренду, но досчитать начатое | `gimps-stop --finish`. Новые задания больше не берутся. Когда `gimps-status` покажет пустой worktodo, выполните `gimps-stop` и удалите инстанс |
| Нужно остановить прямо сейчас, потом продолжу на этой же машине | `gimps-stop`, затем **Stop** инстанса в vast.ai (диск сохраняется). Следующий старт продолжит с чекпойнта |
| Ухожу совсем, досчитывать не буду | `gimps-stop --unreserve`. Задания вернутся в PrimeNet, после этого можно **Destroy** |

`gimps-stop` дожидается сохранения чекпойнтов и **досылает результаты и PRP-proof**.
Не удаляйте машину, пока он не напишет «Готово»: без загруженного proof тест потом придётся целиком перепроверять (double-check).

Перенос на другую машину: скопируйте папку `/data` целиком (`scp -r` или *Copy* в vast.ai) и запустите там `gimps-start`.

## 7. Все настройки (переменные окружения)

Их можно задать через `-e` или записать в файл `/data/gimps.env`.

| Переменная | По умолчанию | Значение |
|---|---|---|
| `GIMPS_USER` | `ANONYMOUS` | Логин mersenne.org. **Обязательно укажите свой** |
| `GIMPS_MODE` | `prp` | `prp` (PRPLL) или `tf` (mfaktc) |
| `GIMPS_WORKPREF` | 150 / 12 | Тип работы PrimeNet: 150 first-time PRP, 151 double-check PRP, 152 world-record PRP, 153 100M-digit, 155 DC с proof; 12 TF |
| `GIMPS_GPUS` | все | Какие GPU использовать, напр. `0,1` |
| `GIMPS_NAME` | `cloud` | Префикс имени машины в PrimeNet. Удобно задать, напр. `vast5090` |
| `GIMPS_DAYS_WORK` | `1` | На сколько дней вперёд брать задания |
| `PRPLL_BACKEND` | `cuda` | `cuda` или `opencl`. Если CUDA-сборка падает, попробуйте `opencl` |
| `PRPLL_TUNE` | `0` | `1` = перед первым запуском выполнить `prpll -tune` (30–90 мин, потом считает на несколько % быстрее). Есть смысл при аренде на неделю и дольше |
| `PRPLL_ARGS` | — | Доп. аргументы PRPLL, напр. `-proof 8` |
| `APN_ARGS` | — | Доп. аргументы AutoPrimeNet, напр. `--cert-work` (брать проверку чужих proof) |
| `PROOF_DISK_GB` | `30` | Сколько диска сообщать PrimeNet под proof на один GPU |
| `DATA_DIR` | `/data` | Где лежит состояние |

## 8. Если что-то не так

- **`nvidia-smi не видит GPU`.** Контейнер запущен без GPU (`--gpus all`), или драйвер хоста слишком старый. На vast.ai выбирайте оффер с CUDA ≥ 12.8.
- **В `prp-gpu0.log` ошибки CUDA/NVRTC.** Задайте `PRPLL_BACKEND=opencl` и перезапустите (`gimps-stop`, затем `gimps-start --daemon`). Проверить OpenCL можно командой `clinfo -l`.
- **`No work to do`** в первые минуты — норма: AutoPrimeNet ещё регистрируется. Если сообщение не пропадает, смотрите `apn-gpu0.log`: там будет ошибка логина или сети.
- **Мало места на диске.** Proof-файлы большие. Уменьшите `PROOF_DISK_GB` или задайте `PRPLL_ARGS="-proof 8"`. Проверка займёт чуть дольше, но засчитается.
- **Подробные логи:** `tail -f /data/logs/prp-gpu0.log`. Собственный лог PRPLL — `/data/prp-gpu0/gpuowl-0.log`.

## Структура

```
Dockerfile                   — двухстадийная сборка (CUDA 12.8 devel → base + nvrtc)
scripts/build.sh             — сборка PRPLL (CUDA+OpenCL), mfaktc, установка AutoPrimeNet
scripts/gimps-start|stop|status
bootstrap.sh                 — всё в одном файле для варианта B (генерируется make-bootstrap.sh)
.github/workflows/build.yml  — сборка и публикация образа в ghcr.io
```
